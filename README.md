# The Shortest Path Problem
A graph is a data structure that connects nodes marked by labels. In a graph, a noted is called a vertex. A connection between two vertices is called edge. The cost to travel through an edge is called weight. 

This Python library works with Dijkstra's Shortest Path Algorithm to find the shortest path from a given source vertex to all vertices.
